# Auction Backend

Backend для аукционной системы с поддержкой WebSocket, Redis и PostgreSQL.

## Основные возможности

- Регистрация и аутентификация пользователей
- Создание и управление лотами
- Система ставок в реальном времени через WebSocket
- Автоставки с лимитом ставок для каждого пользователя
- Боты для поддержания активности лотов
- Планировщик для автоматического завершения лотов

## Автоставки с лимитом

### Включение автоставки
```javascript
// Подключение к WebSocket
const socket = io('ws://localhost:3000', {
  auth: { token: 'your-jwt-token' }
});

// Включение автоставки с лимитом в 50 ставок
socket.emit('enableAutoBid', {
  lotId: 'lot-uuid',
  maxBids: 50
});

// Получение подтверждения
socket.on('autoBidUpdated', (data) => {
  if (data.enabled) {
    console.log(`Автоставка включена. Лимит: ${data.maxBids} ставок`);
  }
});
```

### Получение статуса автоставки
```javascript
// Запрос статуса автоставки
socket.emit('getAutoBidStatus', { lotId: 'lot-uuid' });

// Получение статуса
socket.on('autoBidStatus', (data) => {
  console.log(`Автоставка: ${data.enabled ? 'включена' : 'выключена'}`);
  console.log(`Лимит: ${data.maxBids || 'не установлен'}`);
  console.log(`Текущие ставки: ${data.currentBids}`);
});
```

### Выключение автоставки
```javascript
// Выключение автоставки
socket.emit('disableAutoBid', { lotId: 'lot-uuid' });

// Получение подтверждения
socket.on('autoBidUpdated', (data) => {
  if (!data.enabled) {
    console.log('Автоставка выключена');
  }
});
```

## Особенности работы автоставок

1. **Лимит ставок**: При включении автоставки пользователь обязан указать максимальное количество ставок
2. **Автоматическое отключение**: При достижении лимита ставок автоставка автоматически отключается
3. **Проверка лимитов**: Система регулярно проверяет лимиты всех активных автоставок
4. **Уведомления**: Пользователь получает уведомления об изменении статуса автоставки

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Настройка переменных окружения
cp env.example .env

# Запуск базы данных и Redis
docker-compose up -d

# Генерация Prisma клиента
npx prisma generate

# Миграция базы данных
npx prisma migrate dev

# Запуск приложения
npm run start:dev
```

## Структура проекта

- `src/auth/` - Аутентификация и авторизация
- `src/bidding/` - Основная логика торгов и автоставок
- `src/bots/` - Система ботов для поддержания активности
- `src/lots/` - Управление лотами
- `src/bids/` - Управление ставками
- `src/upload/` - Загрузка файлов
